# VLM 巡检固定考卷（2026-11-02）

从 `temp2/vlm-audit` 的 776 个审核事件中抽样 **200 个事件**，每个事件 4 张图：

- `person.jpg`：全图 + 红框
- `head.jpg`：头肩裁剪（判安全帽）
- `torso.jpg`：躯干裁剪（判反光衣）
- `frame.jpg`：干净 1080p 原帧

图片是快照，已复制到本目录；以后清理 `temp2` 不影响考卷。源数据继续增长，本考卷不自动更新。

## 抽样口径

- **单位是事件**（唯一前缀），不是 CSV 行；一个事件可能同时触发 `no_helmet` 和 `no_vest`。
- **尺寸桶按 bbox 宽度**：`<32`、`32~64`、`64~128`、`>128`（像素）。
- 稀有桶全取（≤40 个事件）：`<32` 27 个、`>128` 35 个；剩余名额按事件数比例分给中间两桶。
- **结果**：`<32` 27、`32~64` 88、`64~128` 50、`>128` 35，共 200。
- **相机分层**：每个桶内按相机分配，相机数允许时每路至少 1 个；共覆盖 20 路相机。
- 随机种子 `20261102`；`build_exam.py` 可复现（重跑会覆盖本目录，标注后不要重跑）。

## 人工标注方法

用 Excel / WPS / LibreOffice 打开 `exam.csv`（UTF-8 BOM，中文不会乱码），只填最后两列：

| 图片 | 填写列 | 含义 |
| :--- | :--- | :--- |
| `图片_head` | `人工_安全帽` | `yes` = 戴了安全帽；`no` = 没戴；`?` = 看不清 |
| `图片_torso` | `人工_反光衣` | `yes` = 穿了带反光条的反光衣；`no` = 没穿；`?` = 看不清 |

规则：

1. **不要先看 `模型_安全帽` / `模型_反光衣`**，先独立标，标完再对比，否则会被模型带偏。
2. `person`/`frame` 只用来理解场景；判定以 `head` / `torso` 特写为准。
3. 图片右侧/下方的灰色区域是补白，不是画面内容。
4. 安全帽：硬质帽壳（常见黄/白/红/蓝/橙）；布帽、遮阳帽、草帽、头巾本身不算；帽子上加装防晒帽檐/遮阳披肩/护颈布，只要能看出硬壳，也算戴了；正面/侧面/背面同样适用。
5. 反光衣：带反光条的反光工作服，颜色深浅不限，背心/马甲/长袖/短袖均可；没有任何反光条的普通衣物算 `no`。
6. 看不清、目标被裁掉、不是真人 → 填 `?`，评分时排除，不要猜。
7. 统一小写：`yes` / `no` / `?`。

## 负样本 `negatives.csv`

从巡检的**单规则事件**里补的“另一项已穿戴”样本：

- `安全帽-已戴` 50 张：来自只触发 `no_vest` 的事件，取 `_head.jpg`；`人工_安全帽` 留空，`人工_反光衣` 预填 `-`。
- `反光衣-已穿` 50 张：来自只触发 `no_helmet` 的事件，取 `_torso.jpg`；`人工_反光衣` 留空，`人工_安全帽` 预填 `-`。

注意：单规则事件只说明另一项**没有被判违规**，理论上可能是 `yes` 也可能是请求失败（`None`）。CSV 里写 `yes(未违规)` 只是弱标签，**以你的人工标注为准**。如果标出来是 `no`，这张就不是负样本，而是模型漏报/误判的案例，仍然保留。

负样本同样只填对应的一列：`yes` = 确实戴了/穿了，`no` = 没有，`?` = 看不清。

## 评分建议

- 只统计已填 `yes`/`no` 的行，`?` 排除。
- 按 `尺寸桶`、`相机`、`规则` 分别报，不要只看总体准确率。
- 对每个规则做四格：

|  | 人工 no（违规） | 人工 yes（合规） |
| :--- | :--- | :--- |
| **模型 no（判违规）** | 真违规 | 误报 |
| **模型 yes（未判违规）** | 漏报 | 真合规 |

- 这是“低置信候选池”的考卷，不是随机分布；指标是条件于候选池的，不要直接当全量召回率。
- 不要用考卷调提示词；要调就另留 30% holdout，或等这批标完后再建下一版考卷。考卷一旦被用来调参，就不能再当独立评估。
