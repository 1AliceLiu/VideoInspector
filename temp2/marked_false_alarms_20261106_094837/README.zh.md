## 时序与置信度局限

全部 26 条记录都与证据时序日志匹配：偏差 80–400 ms，中位 100.5 ms。这是真实存在的不匹配，但无法解释所有"静止安全帽"错误。保存的 JPEG 是带标注的快照，并非精确的决策帧。回放使用 FP16 PyTorch，不是精确的 DeepStream/TensorRT 预处理。仅凭这些案例不能测量查准率/查全率，也不能确定回退模型是否安全。
